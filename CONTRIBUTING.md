# Contributing to ORBIT

Thanks for helping build ORBIT.

## Development

Requirements:
- macOS, Linux, or Windows
- Node.js 22+
- npm
- Electron 44+

Run:

```bash
npm install
npm start
```

## Product principles

- **Local-first:** user knowledge belongs to the user.
- **Provider-agnostic:** ORBIT should work with local and cloud models.
- **Goal-aware:** intelligence should accumulate against the user's evolving goals.
- **No fabricated research:** never imply live browsing when the active runtime has no web-search capability.
- **Useful over noisy:** surface changes, implications, and questions—not a firehose of links.

## Pull requests

Keep changes focused. Explain the user problem, the proposed behavior, and any persistence/schema implications.
